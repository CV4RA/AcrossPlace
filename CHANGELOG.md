# Release 1.0.0

First public AcrossPlace source release: construction and append-only expansion; fixed P0/P1 protocols; independent pretrained-to-trained baseline workflows; evaluation guards; automatic and human diagnostics; archived quantitative evidence; local coarse query/index CLI; public English website with original data and recorded predictions.

Retrieval numerical recipes and evaluation logic are preserved from the verified experiment implementation. The study planner parameterizes model/image paths and P0/P1 choice. The portable study test driver freezes all completed validation choices before tests. A missing local generation model path now produces a local-file error instead of being treated as a Hugging Face repository identifier. Server provisioning, credentials, cleanup and shutdown helpers are excluded.
